# Домашний экран tvhome (com.gio.tvhome)

В проекте используется ультралегковесный лаунчер для Android TV, созданный автором проекта debloat-google-tv (Gio Turmanidze).

---

## 1. Преимущества перед штатными лаунчерами

| Параметр | Штатный StarLauncher / Emotn | Новый tvhome (`com.gio.tvhome`) |
|---|---|---|
| **Используемая ОЗУ (PSS)** | 110 – 160 МБ | **~47 МБ** (экономия >100 МБ ОЗУ) |
| **Java Heap** | 15 – 35 МБ | **Всего 1.3 МБ** |
| **Реклама и промо-блоки** | Присутствуют | **Полностью отсутствуют** |
| **Анимация обоев** | Статичные / тяжёлые веб-вью | Встроенные WebP 1080p с мягким кроссфейдом |
| **Погода** | Требует ключи / геолокацию | Автоматически по IP через Open-Meteo |
| **Размер APK** | 15 – 70 МБ | **4.5 МБ** |

---

## 2. Интерфейс и структура

1. **Верхняя строка (Статус):**
   - Контекстное приветствие по времени суток («Доброе утро», «Добрый день», «Добрый вечер», «Доброй ночи»).
   - Крупные системные часы и дата на русском языке.
   - Погода: город, температура и описание (например, `Khujand +15° переменная облачность`).
   - Иконка быстрых настроек Android TV в правом верхнем углу.
2. **Первая строка плиток (Док избранного):**
   - Быстрый доступ к главным сервисам (SmartTube, VK Видео, Иви, RUTUBE, IPTV, Зона).
3. **Вторая строка («Все приложения»):**
   - Сетка всех остальных установленных приложений устройства.

---

## 3. Управление пультом ДУ

- **Перемещение фокуса:** Стрелки навигации пульта (`Вверх`, `Вниз`, `Влево`, `Вправо`).
- **Запуск приложения:** Одинарное нажатие клавиши `OK` (`DPAD_CENTER`).
- **Добавить / Убрать из Дока (Избранного):**
  - Наведите курсор на плитку приложения.
  - **Зажмите и удерживайте клавишу `OK` на пульте (длинное нажатие).**
  - Приложение автоматически добавится в верхний док (или уберётся из него, если уже там было).
- **Выход на домашний экран:** Нажатие клавиши `Home` («Домик») на пульте возвращает на главный экран за миллисекунды.
